# Kaiju-Geddon! — M7 QA build / M5 combat pending

Browser arcade destruction game, implemented incrementally from the supplied Master Prompt and Final GDD. Current build has a six-city campaign (San Francisco, then New York, Mexico City, Paris, Hong Kong and Tokyo; 34 route levels), military/civilians, local persistence, roster previews, Free Play, intro and ending/gallery flows. **The user requested M6 after M4; M5 was skipped.** All unlocked identities can now be selected with temporary geometric visuals, but they share the existing player combat, stage dimensions/stats and Seismic-style Ultimate preview. Ratings are provisional display data, not implemented per-kaiju tuning. Rivals still use the basic shared M4 preview moveset. Individual kaiju movesets, boss evolution/Ultimates, full knockback interactions and boss introductions remain M5. No claim that M5 is complete.

## Launch and checks
Requires Node.js 24+; no package downloads or runtime dependencies.

```
npm run build
python3 -m http.server 8080 --directory dist
```

Open http://localhost:8080. `npm test` builds then runs deterministic rule/state and actual-game-loop tests. `npm run check` checks emitted JavaScript syntax. `npm run qa` runs the complete 34-level keyboard simulation and writes `qa/playthrough.json`. See `QA_REPORT.md` for exact results and release blockers. Native Node TypeScript stripping is used; no TypeScript typechecker or lint tool is configured. Production is a static site. HTTP previews use a non-security-sensitive local ID fallback when crypto.randomUUID is unavailable.

`npm run build:artifact` builds the page for publishing as a claude.ai Artifact: `dist-artifact/index.html` (stylesheet inlined, all modules bundled into one classic script, no outside requests except Google Fonts) plus the sprite sheets in `dist-artifact/assets/` and `dist-artifact/files.json`, the list to pass as the publisher's supporting files. It reads `src/` and `public/` directly, so it does not need `npm run build` first. The Artifact viewer did not render the multi-file `dist/` build, so publish this instead. Any script error shows as a red bar at the bottom of the page. See *Artifact build* below.

## Controls and flow
A/D move; H grab what's in front (car, van, bus, any wreck, an enemy patrol car/APC/tank/artillery piece, a newsstand/stronghold barricade, a lamppost, or at Stage 3 a whole building up to mid-rise size) and carry it overhead, then H/J/K throw it (hold W to lob it upward at aircraft); W climb the side of a building (grab, W up / S down, hang in place when idle, Space to jump off, mantles onto the roof; J while clinging is a one-armed punch into the wall, `climbPunch`, an 8-frame 256x256 strip per stage generated with PixelLab from that stage's climb loop frame 0); S stationary crouch; Space jump; stand on any rooftop; J repeated presses for the three-hit light combo; K tap/hold and release heavy; L horizontal ranged spine (Mogurodon on the ground: Tremor Slam; Kaiban on the ground: Debris Shotgun); U full-meter Seismic Rupture (Kaiban: Stampede; Tlézcatl: Eruption; Belial: Acid Deluge); I full Stage-3 HP and full Super charge; Esc pause; the pause menu's **Moves & Controls** panel lists the active kaiju's signature moves and the shared combat moves (Moves tab) and movement/climbing (Controls tab), from `moveList()` in `src/presentation.ts` (key notation: `+` held, `/` alternatives, `›` in sequence). The in-game hint is now just a short 'ESC: PAUSE · MOVES & CONTROLS' for the first 8 seconds of a block. No crouch-jump. **Movement and aerial attacks (`MOVE` in `src/config.ts`):** hold Shift or double-tap A/D to run (1.8x; the double-tap opens with a 0.2s dash burst at 2.7x and stays latched until both keys are released); running into a building shoulder-barges it (`bargeDamage`, 1.5x during the dash, on a cooldown) once you have a run-up (`bargeRunUp` px x stage scale covered running the same way; each hit spends it, so holding run against a wall cannot repeat) and bowls over troops; a running jump keeps run speed in the air and goes slightly higher, and jump height grows a little with stage (`jumpVelocity × stageScale^0.25`). Steering into a wall while airborne grabs it without W (leap-grab); if your feet are within `ledgeGrab` body heights of the roof you pull straight up onto it. Pushing into the wall while clinging climbs like W, and Space with the away direction held kicks off the wall into a running leap. S in the air is the Slam: a straight dive (`diveSpeed`, a little steering) that hits the roof under you for `diveDamage × diveRoofMult` plus everything in `diveRadius`, scaled up by the drop height; if the roof gives way you keep plunging into whatever is below, and on the street it rolls out a short shockwave both ways. S+J (crouched light) is the Pound: it beats down on whatever you stand on, so on a rooftop it hammers that building (combo multipliers apply; plays `ultPound`, falling back to `heavySlam`), and on the street it stomps troops, cars and newsstands at your feet. Covered by `tests/movement.test.ts`. Forms can override the borrowed Slam art with their own `dive` (played from the start of the dive, held on its last frame; with `pivot` and `spinFrom` the game rolls it forward about that point at `diveSpin` rad/s) and `slamLand` (played from impact). Mogurodon Stage 1 has both: `mogurodon-s1-dive.png` tucks from the airborne gallop into a quills-out spike ball (frames 0-2 of a 9-frame PixelLab generation from the jump-air pose, bottom-aligned, 28 fps so the ball shows for most of a short drop), and `mogurodon-s1-slam-land.png` is frames 1-8 of a generation from that ball resting on the ground to the base pose (seed 11): squash flat in a dust ring, rebound, burst out of the ball and settle. Eye restored with `fix_eye.py --region 115,140,170,195 --max-err 9000` (the curled frames have no visible eye), then `fill_pinholes.py` and `remove_specks.py`. Mogurodon Stage 2 (`mogurodon-dive.png`/`mogurodon-slam-land.png`, base form) and Stage 3 (`mogurodon-s3-dive.png`/`mogurodon-s3-slam-land.png`, a crystal-studded ball) are made the same way (dive frames 0,1,3 for Stage 2 to skip a specky frame, 0-2 for Stage 3; slam seed 11 for both; pivots are each ball's alpha centroid; eyes restored with `--region 110,132,185,205` and `92,110,185,202`). Kaiban still borrows `jumpAir`/`heavySlam`. **Run art:** while running, a form's `run` loop replaces the sped-up walk (1.3x faster during the dash burst). Mogurodon Stage 1's `mogurodon-s1-run.png` is an 8-frame bounding gallop generated from the base with the base as the last frame (seed 0; the closing duplicate is dropped), 15 fps; the two airborne frames stay lifted so the run bounces. The eye on the leap frames needed `fix_eye.py --radius 34 --max-err 12000 --only 2,3,4,5` because the head travels ~30px. Stage 2 (`mogurodon-run.png`, seed 0, the longest reach) and Stage 3 (`mogurodon-s3-run.png`, seed 11, with an airborne gather mid-cycle) are made the same way from their bases; eyes via `fix_eye.py --radius 34` with each form's region, Stage 2 also `remove_specks.py ... 256 12` for dust flecks. **Cannonball roll:** two ways in. Run + S on the ground curls up on the spot and rolls the way you are running (base power). Or Slam: if A/D is touched at any point during the dive (latched on the key press, so even a one-frame tap counts), or the dive came out of a running leap, the landing keeps the ball rolling that way, on the street or a rooftop (a roof the slam crashes through drops you to whatever is below first). It rolls (`rollSpeed` x walk speed x sqrt(stage scale), `rollSeconds`) for forms whose dive strip spins (Mogurodon); input steers nothing, attacks/grabs are ignored, Space jumps out with run speed, and holding the opposite direction bursts out early. It hits each troop, car (punted), newsstand, growth, rival and stronghold crystal once (`rollDamage` x the slam's drop power). The first wall takes `rollWallDamage` and the ball ricochets back with a hop (`rollHop`, at most `rollAfterBounce` seconds left); the second wall or running out of time ends it by playing `slamLand` (from the squash after a wall, from the rebound frame otherwise). Fullscreen button on the page. Keyboard required.

Main Menu → New Campaign → skippable 12-second asteroid intro → exactly three letters → unlocked kaiju selection → campaign route → Begin City → five blocks → City Conquered → campaign route → next city. Continue loads the last city-boundary checkpoint. New Campaign confirms before replacing an unfinished run. Mogurodon is initially selectable; existing and newly earned rival unlocks enable their identities in Campaign and Free Play. Their distinct attacks/stats remain M5 and this limitation is shown at selection. Locked characters show static silhouettes/question marks, cannot be selected or previewed. An unlocked selection has animated idle stand-ins for all three stages and four provisional 1–5 ratings. Combat Drills retain the M3 tier selector on the original NYC map, do not touch campaign state, and are not leaderboard eligible.

## Campaign rules
- Order: New York/Kaiban, Mexico City/Tlézcatl, Paris/Belial, Hong Kong/Myrmex, Tokyo/Sargathoth. Order after NYC remains an editable implementation default.
- Every city has five hand-authored building/population layouts with 4/6/8/8/4 screen widths. Districts are packed with solid, wall-to-wall buildings you must smash through, climb or hop across; only tiny newsstands are walk-through. The original authored NYC layout survives as the Combat Drills map, and the old packed Lower Manhattan wall is kept as `DRILL_BLOCK`, which Combat Drills loads. **Open layouts (NYC Blocks 1/2/4, pilot):** buildings stand in clusters separated by streets and plazas; the player spawns mid-map (`BlockDef.start`), can roam both ways, and leaves by either the west or east exit once the quota is met. Each has named landmark towers (`L` preset: high value, stepped crown/spire, street-level gold name banner) and hidden crystal caches (an occasional pink window glint, exposed vein when damaged). Landmarks/caches pay score plus Ultimate charge (`EXPLORE` in `src/config.ts`) and never extra crystals. A bottom-strip minimap shows the whole block: skyline, gold landmarks, exposed caches, hostiles, objective/rival, exits, view window and player. Other cities still use the packed layouts. Runtime expands reusable building presets, never generates layouts procedurally.
- **City systems (every open block: Lower Manhattan, Midtown, and blocks 1, 2 and 4 of the other four cities; `CITY` in `src/config.ts`, logic in `src/city.ts`, wiring in `src/game.ts`).** Phase 1 of the city overhaul, to test whether buildings with jobs plus a momentum meter fix the walk-and-punch sameness. **Rampage:** every point earned goes through one `award()` path; heat climbs with points and building damage, holds for `rampageGrace` seconds, then drains. Levels multiply score ×1/1.5/2/3/4 (×4 is UNSTOPPABLE); topples, explosions, blackouts, splashes and live wires add bonus heat. It shows as a panel under the block name. **Power grids:** the block is split into a west and an east grid (`BlockDef.grids`), each fed by a fenced substation (`S` preset). Destroy one and its grid blacks out: lit windows go dark, rooftop radars there go offline, spotter radios there lose signal (no artillery calls), and live wires die. **Fuel depots** (`F`) explode when destroyed: area damage to military, buildings, rooftop fixtures and vehicles, chain to other depots, burning fuel left on the street. Substations and depots are low yards you walk past (tiny kind, never wall off a street) but do not break on contact. **Rooftop air-defence radars** (`roof:'radar'`) sweep while powered; with the kaiju in range and the building in view they build an 11 s call (dish tracks you, red lock line in the last half) and drop a marked artillery strike. Climb up, shoot or throw something to break them (+score, +Ultimate). **Water towers** (`roof:'tank'`) burst when hit or when their building falls: a water column and a sheet along the street knock troops down and stun them, shove cars and douse fires. **Power poles** (`BlockDef.poles`, lamp-kind props, grabbable as javelins) carry wires between neighbours; a pole knocked out of upright on a live grid drops a live wire between its neighbours that zaps and stuns ground units for 9 s. Splashes and live wires pay points but never charge the Ultimate. **Delayed collapse:** a destroyed tower creaks for 0.6 s (0.3 s for chain topples, none for Ultimate damage), still solid, shuddering and shedding slabs, before it falls. **Debris that hits:** slabs from collapses, creaks, topple landings and depot blasts damage the first ground unit they land on and punt cars. The minimap marks substations (blue), depots (orange), radars (red) and water towers (pale blue), with grid status beside it. Covered by `tests/city.test.ts`.
- **Street junk and city skins.** Every district street (not drills or boss arenas) gets per-city walk-through clutter beside the road (`BuildingSpec.prop`, appended in `district()` in `src/levels.ts`: up to three in every gap between solid buildings, on flat pavement or a gentle slope, kept clear of the start plaza, newsstands, yards and hydrants): hot-dog carts and trash cans in New York, taco stands in Mexico City, Morris columns and café tables in Paris, dai pai dong stalls in Hong Kong, vending machines in Tokyo. They break on contact into coloured chunks for small points. The city-systems kit (substations, fuel depots, one rooftop radar per block, rooftop tanks, pole lines) is spread to every open block by `powered()`; Hong Kong has no yards (its gaps are ramps) and Paris has no overhead lines. Tanks and poles are skinned per city: black plastic tinacos in Mexico City and Tokyo, concrete cisterns in Hong Kong, zinc ones in Paris; concrete poles with pole-top transformers in Tokyo and Hong Kong, wooden poles with tangled taps in Mexico City.
- **Terrain and floors (phase 2 foundations; `src/terrain.ts`, `FLOORS` in `src/config.ts`).** **Ground profile:** the street no longer has to be flat. `BlockDef.ground` is a list of [x, y] points (authored as [x, rise] pairs through `terrain()` in `src/levels.ts`) joined by straight lines; `groundAt(x)` answers the street height anywhere and every system uses it: the kaiju's footing (it snaps down slopes instead of hopping), military units, traffic, parked cars, wrecks, civilians, the rival, projectiles and artillery, shards, debris, pools, shockwaves and drawing. Buildings carry `base` (the highest ground under their footprint) and stand on flat stretches; slopes go in streets and plazas. Blocks without a profile are flat at `CONFIG.ground` exactly as before. **Pilot: Midtown Corridor** (NYC Block 2) has a sunken start plaza with ramps either side and a cluster of buildings on a raised terrace east of the plaza. **Floor stacks:** every ordinary building is a stack of floors about `floorHeight` tall. Each hit also wears the floor it lands on (integrity = `integrity` x that floor's share of HP). A worn-out floor below others pancakes: the building drops one storey, dust blows out at its foot and troops and cars crowded round it are crushed. A worn-out top floor is knocked off, taking any rooftop radar or water tower with it. Floors past half integrity show a crack, past a quarter a deep one. HP and destruction are unchanged, so towers still topple when their HP runs out, just shorter if floors already failed; undercutting a tower from the street usually pancakes two or three floors on the way. Covered by `tests/terrain.test.ts`.
- **Rivers, bridges, subways, shearing and armories (phase 3; `RIVER` and `FLOORS.shear*` in `src/config.ts`).** **Pilot: East River Offensive** (NYC Block 4). **River:** `BlockDef.water` spans with a surface height over a dipped riverbed. The kaiju wades at `wadeSlow`; ground troops stop at the bank and never spawn in open water, so the bridge is their only way across; troops or vehicles that end up in the water (knocked in, or dropped with a span) drown or sink, credited to the player; civilians swim away; fires go out. Deep water is drawn behind everything and a translucent layer in front of whatever wades. **Bridge:** `BlockDef.bridge` is a street-level deck in three breakable spans (`spanHP`) under Brooklyn-style stone towers, main cables and suspenders. While a span stands its deck is the ground (`groundAt` in `src/terrain.ts`). Break it by pounding or slamming it from on top, hitting it from below or beside, blasting it, toppling a tower across it or landing a sheared top on it; it swings down into the river and everything on it goes too. **Subway:** `BlockDef.subway` marks a line under the street (the west half of East River). A slam on the street over it, a tall tower landing across it or a building chunk landing on it caves the street in: a pit `pitDepth` deep that troops fall into and cannot climb out of (walls and banks steeper than 12px block them). Slamming inside an existing pit doesn't dig it deeper. Cars that drive into a pit careen off the edge and explode when they land. **Trains** run the line every `trainEvery` seconds whether or not the street is open, shown in a cutaway strip under the street (tunnel lights, rails, lit carriages). Through a pit they hit troops and vehicles down there, and they can be attacked (`trainHP`: punch, pound, slam, shoot, or blow something up next to one). A train that reaches the kaiju standing in a pit smashes into it and derails (a little damage and a shove for the kaiju, `trainPoints` for you); a derailed train lies burning in the tunnel and the next one piles into it. At Stage 3 the kaiju can reach down through a pit and pull a whole train out (running or wrecked) with H: a 3-carriage prop (`train` vehicle, mass 6) carried overhead and thrown like anything else, exploding on impact; snatching a running train pays `trainPoints`. Combat Drills now has a short subway line at its far east end for practising cave-ins, trains and train snatching. After `trainWrecks` (3) derailments the line closes and no more trains run, so it can't be farmed. The tunnel sits `tunnelRoof` below the street under a concrete roof, leaving a solid band of street over the buried line; pits cut through it to the tunnel floor. The bottom HUD meters sit lower so the cutaway stays visible. **Shearing:** a single blow of at least `shearDamage` (a fully charged Stage 3 heavy, a thrown bus at Stage 3, a fuel depot blast) on a middle floor of a building with four or more floors breaks it there: that floor is crushed and everything above flies off the way the blow went as one spinning chunk that smashes what it hits, breaks up where it lands, drops bridge spans and caves in the subway. Crush damage from a falling tower never shears. **Armory** (`K` preset): a solid castle-style drill hall at each end of East River; destroying one stops squads arriving from that side for `armorySeconds` (shown under the hostile count). **Free Play start block:** Free Play now has a START BLOCK choice, so any block of a conquered city can be played directly. Covered by `tests/river.test.ts`.
- **City identity (phase 4; `CITIES` in `src/levels.ts`).** Each city now has its own look. **Mood:** sky gradient and time of day (New York warm afternoon, Mexico City smoggy golden dusk with Popocatépetl smoking, Paris soft overcast with the Eiffel Tower and Sacré-Cœur on the horizon, Hong Kong at night under Victoria Peak, Tokyo on a rainy night with Fuji, Skytree and Tokyo Tower), stars and lit windows at night, rain streaks in Tokyo, smog in Mexico City; HUD text over the sky switches to light ink on night skies. **Facades** (`style`): New York brick with fire escapes and cornices; Mexico City pastel stucco with iron balconies, ground-floor arcades and black rooftop water tanks; Paris limestone with mansard roofs, dormers, chimney pots, balconies and café awnings; Hong Kong tiled towers with air-con units, laundry poles and hanging neon; Tokyo glass curtain walls with vertical neon and rooftop billboards. Footprints and hitboxes are unchanged. **Landmark silhouettes:** `L` landmarks take an optional shape (`NAME|shape`: lattice, dome, twin, arch, needle, pagoda) drawn as the monument (Tour Eiffel, Notre-Dame, Bellas Artes, Bank of China, Skytree, Sensō-ji…); the hitbox stays the box. **Materials:** debris comes in the city's material (brick, stucco, heavy limestone blocks, glinting glass in Hong Kong, steel and glass in Tokyo, where a collapsed tower leaves its steel frame standing). Holes punched in facades show lit rooms. **Street life:** each city has its own car colours and a taxi livery with roof signs (yellow cabs, pink-and-white, black, red, navy). **Open layouts everywhere:** blocks 1, 2 and 4 of every city are open layouts with a central start plaza, clusters with streets between, three or four named landmarks and hidden caches.
- **Fire, rubble, hills and city twists (phase 5, first half; `FIRE`, `RUBBLE`, `TWISTS` in `src/config.ts`).** **Fire:** buildings catch fire and it spreads. A fuel depot blast sets the buildings around it alight; a burning wreck smashing into a wall can (`wreckChance`); fire on the pavement beside a wall, or a wall scorched by Tlézcatl's flame, builds up exposure until it catches. A burning building takes damage as the heat climbs (points, never Ultimate charge), shows flames in its windows and on the roof and a smoke plume, and builds exposure on any neighbour within `reach` until that one catches too (at most `cap` burning at once). Rain (Tokyo) halves growth and spread; a burst water tower douses everything near it. Ignition is deterministic exposure, not dice, so fire behaves predictably. **Rubble:** a collapsed building leaves a heap over its footprint and a toppled tower leaves a ridge where it fell, raising the ground (`moundAt` in `src/terrain.ts`) so the kaiju, troops and traffic climb over it. **Hong Kong hills:** its three open blocks climb a hillside toward the Peak, each cluster on its own terrace with ramps in the streets. **City twists:** New York has the subway; **Mexico City** has soft lake-bed ground, so slams, topple landings and depot blasts sink nearby buildings (landmarks too) and a building sunk far enough gives way; **Paris** has catacombs under every street, so a slam caves in anywhere (an ossuary of stacked bones, no trains); **Hong Kong** towers go down like dominoes (crush falloff and chain strength raised); **Tokyo** towers are quake-proof, swaying off blows and taking half damage from anything under `quakeBreak`. Kills during an Ultimate no longer cause hitstop. Covered by `tests/phase5.test.ts`.
- **City response, water mains, tunnels and Tokyo's elevated line (phase 5, second half; `RESPONSE`, `MAINS`, `TUNNEL`, `ELEVATED` in `src/config.ts`).** **City response:** as a block's destruction passes 20% / 45% / 65% the city escalates (banner plus an ALERT panel under the rampage gauge): **evacuation** (every civilian flees, roadblock barriers go up ahead of the kaiju on both sides, grabbable and throwable), **martial law** (the military response steps up a tier and the buildings still standing are reinforced, shown by sandbags, +20% HP), and from block 2 on an **air strike** stage (a bombing run walks marked strikes across the kaiju every 20 s). Not in drills or boss arenas. **Water mains:** fire hydrants stand on the pavement beside district streets (appended to each block's buildings, flat ground only, not grabbable). Walk into one and the main bursts into a geyser for 4 s that shoves and stuns troops, pushes cars and puts out fires. **Tunnels:** at Stage 3, shoulder-barging a building at street level (or off a rubble heap) tall enough to fit the kaiju bursts a walk-through tunnel in it. A charged heavy still shears instead. **Elevated railway (Tokyo blocks 1, 2 and 4):** a concrete guideway on T-pillars just under a standing jump's height, in breakable spans. The kaiju can stand on it; white-and-green trains run along it every 6 s. A train that reaches the kaiju on the track smashes into it and is thrown off, falling to the street as an exploding train; one that reaches a broken span falls through. Spans break like bridge spans: pound or slam them from on top, hit them from below, blast them, topple a tower across them. Covered by `tests/phase5b.test.ts`.
- **San Francisco Act 2: Nob Hill, Financial District, Fisherman's Wharf (campaign redesign phase 4; `RUNAWAY`, `SF2`, `FOG` in `src/config.ts`, `src/rolling.ts`, `src/ship.ts`, `src/fog.ts`).** All opt-in per level (`BlockDef`, documented in `src/levels.ts`). **Runaway physics:** a vehicle in the `rolling` state moves by the street's `slopeAt` alone: it speeds up downhill, coasts to a stop on the flat and wrecks on impact (`rollDamage`: a building it destroys is bowled through with `plowKeep` of its speed, up to `plows` of them; one left standing wrecks the car on the careening-car launch). **Nob Hill** (7 screens, destruction, Stage 2): a terraced hillside from `terraced()` (pattern tokens `~N` ramp gap, `^R` new terrace) with stair-stepped Victorian rows; cable cars shuttle on `cableLines` and can be grabbed; destroying the `powerhouse` (role) sets every one loose; the Guard's APCs hold the summit park; Lombard Street's `tumble` zone lets parked cars go downhill when the camera nears. **Financial District** (7 screens, target: the pyramid tower, art `pyramid`): tanks and helicopters (`units`, with an altitude for aircraft), the bank vault (`m:vault`, a cache that spills gold), the transit center (`elevatedLook: 'park'`: the elevated system drawn as a roof park over `buses`; a span that falls crushes them), a helipad roof fixture and flanking towers that topple onto the pyramid (a toppled tower now damages the objective). The camera's 560px rise is enough for the tallest tower (checked in `tests/sf-act2.test.ts`). **Fisherman's Wharf** (8 screens, target: the Coast Guard cutter, art `cutter`): open layout with two exits routed by `BlockDef.exits` (`exitTarget` in `src/campaign.ts`: west to The Fault, east to the Alcatraz placeholder, which rejoins the route through `after`); piers are street-level plateaus between water slips (wading at Stage 2), the bay is over a Stage 2 kaiju's head and wading depth at Stage 3, so the crystal on Pier 39 (`capLift: 3`) opens it; the cutter is a floating stronghold (`src/ship.ts`: `createShip(x, scale)`, it sinks when destroyed; a larger scale makes the aircraft carrier); sea lions flee into the water, Kaiban's silhouette roars in the fog (`fog: {from, to, max}`, `fogAt`, reused later by the Golden Gate). Tests: `tests/rolling.test.ts`, `tests/sf-act2.test.ts`.
- **Alcatraz, the secret tenth level (campaign redesign phase 6; `ALCATRAZ` and `sfAlcatraz` in `src/levels.ts`).** Built only from existing systems and procedural art. Reached through the Wharf's east exit (Stage 3 wading out after the cutter sinks); both of its exits are on land and lead on to The Fault, so the Wharf counts as cleared. A 4-screen district with a 90% exit threshold (`exitAt`): a land spit, the cove (a ford every stage can wade, Coast Guard boats), the dock, a switchback road up three terraces (guard tower; the old water tower with its tank splash), the cellhouse summit (crystal cluster, workbenches, hazmat soldiers via `hazmat`, helicopters, a fuel cell schematic and a surveillance photo of Kaiban drawn on its wall) and the lighthouse. Clearing it in the campaign (`secretId`) adds it to `Permanent.secrets`: it becomes a Free Play start block and a gallery entry, and the results screen shows `lore` ("PROJECT MK: FUEL SOURCE CONFIRMED."). Tests: `tests/alcatraz.test.ts`.
- **San Francisco Act 3: The Fault, Bay Bridge, Golden Gate (campaign redesign phase 5; `CRACK`, `GAS`, `BRIDGE`, `GATE` in `src/config.ts`, tests in `tests/sf-act3.test.ts`).** All Stage 3 (start 3, cap 3, soft floor to Stage 2) with the full military. **The Fault** (8 screens, destruction): three fault cracks set off by any slam, pound or Ultimate (an Ultimate reaches further and quakes harder); each is a district quake (shake, falloff damage, sway, the existing shockwaves both ways) that bursts the gas mains into fire geysers; the level raises the burning-building cap (`fireCap`); the third crack is the Big One: the whole level shakes and the double-deck freeway (the elevated system, `elevatedDecks: 2`) pancakes column by column, upper deck then lower, crushing what is under it; the on-ramp at the east end is the exit. **Bay Bridge** (8 screens, target: aircraft carrier): decks stand `bridge.rise` above the water; the west span is a double deck (lower deck = the road spans, upper deck = a long building on two climbable towers using stacked-tier hit parts, with a terrain platform so troops stand on it); breaking the upper lands you on the lower, breaking the lower drops you into the chest-deep bay (wade at Stage 3); gunboat (tank logic) and destroyer (artillery logic) are new naval units that work under a deck; Treasure Island is the breather; the carrier is the cutter hull scaled up (`target.scale`), with a walkable flight deck that sinks with the hull and existing jets launching off it. **Golden Gate** (6 screens, boss): two screens of approach, then the bridge; Kaiban waits in the fog (dormant, untouchable), the placeholder rival moves run, plus the fog charge (vanish, roar and silhouette, charge), the deck gives way under both kaiju at each health break, and at 0 health Kaiban retreats (not KO'd) while the main span comes down; `conquerCity` then unlocks Kaiban and New York. Parked, not built: army demolition teams, drop-through-deck move, Yerba Buena tunnel, Kaiban's own moveset.
- Blocks 1/2/4 require 75% of building value, then the player must physically enter the eastern exit. 100% earns one Perfect bonus. Block results show destruction/objective status and block/campaign totals. Backtracking stays within the current block.
- Block 3: fortified central crystal, 700 provisional HP, fixed defenses and normal reinforcements. Destroying the crystal latches the objective and drops 35 collectible shards; it does not fill HP directly. Walk to the eastern exit to advance. Building quota does not gate this block.
- Block 5: locked four-screen destructible arena, limited military, basic rival conventional HP bar, shared telegraphed melee/ranged attacks, foot pursuit, physical blocking and no contact damage. Only player damage hurts rival. Rival death immediately wins the city before later incoming hits. No boss crystal drops. These encounters intentionally lack M5 character-specific/evolution/Ultimate behavior and skippable boss intros.
- HP/evolution, Ultimate, stored Super charge and active Super duration carry across blocks. Interstitials freeze simulation. Transient input/charge/cooldowns and per-block entities reset. Beginning the next city resets HP to Stage 1, Ultimate/Super and city score; previous city totals remain banked.
- Pause Restart City requires confirmation and resets Block 1, all current city points/damage penalty, HP/evolution/Ultimate/Super. Earlier banked scores remain. Quit warns that current city progress is lost; Continue starts its Block 1. No individual block restart in campaign.
- Death finalizes the run, removes its checkpoint and records its total once. No campaign retry after death. New campaigns remain available; drills can retry.

## Local storage and scores
Two independent versioned keys: `kaiju-arcade:permanent:v2` (unlocks, conquered city ids, gallery slots, Top 10) and `kaiju-arcade:campaign:v2` (run ID, initials, kaiju, campaign position, banked score). v1 saves from the five-city campaign are discarded at boot, not migrated. Saves occur at the initial pre-city boundary and after a city is conquered. No mid-block writes. Between-city Continue starts the next city at Stage 1. Permanent progress survives death/restart/new campaigns. Corrupt/unsupported saves and blocked storage are handled without crashing; failed storage displays a notice and in-memory play still works.

Score is earned points minus actual HP damage penalty, including healed damage. Current city penalty persists across blocks. Top 10 includes completed and failed campaigns, sorted by total (negative scores allowed), with initials, kaiju, cities and outcome. Run IDs and completion latches prevent duplicate records/rewards. Drills never write records, unlocks or checkpoints.

## Combat and military
- **Traffic and vehicles (`VEHICLES` in `src/config.ts`, `src/vehicles.ts`).** Parked cars plus passing traffic (cars, vans, buses) in two road lanes: eastbound in the far lane behind the kaiju's feet, westbound in the near lane in front. Traffic enters from off-screen, brakes when the kaiju is ahead, U-turns and flees faster; each district/stronghold has a traffic budget (5 per screen, none in arenas or drills) and traffic pays half points so it cannot be farmed. Melee, spines and Ultimate waves punt vehicles into tumbling projectiles; stepping squarely on one flattens it (the body's outer edge is a grab zone). Thrown/punted vehicles damage buildings, military, the rival, objectives and growths, and knock other vehicles flying; mass slows them and scales damage, throws also scale with stage. They bounce and settle as grabbable, smoking wrecks. Carrying slows movement slightly and blocks climbing; a stagger, transform or Ultimate drops the vehicle. Grabbing an enemy ground vehicle captures it: it stops fighting and pays its kill points (no crystals, no wreck). Lifting a structure 50px or shorter destroys it for score/quota and leaves no rubble. At Stage 3 the kaiju can also rip up whole buildings up to mid-rise size (up to 240px tall and 115px wide, so every `s`/`m` preset but no `h` tower or taller, never landmarks; `liftHeightStage3`/`liftWidthStage3` in `FEEL`): the building is destroyed for score/quota on lifting, carried overhead at its full size as a `building` prop with mass from its footprint (area/2500, clamped 3-6), and breaks into rubble where it lands instead of settling as a re-grabbable wreck. Grab targets are ranked by their gap from the body's leading edge, so whatever is directly in front wins over props under the wide Stage 3 body. Street lamps (every 450px, formerly backdrop art) are props: walking through one knocks it flat, a hit snaps it off, and grabbing uproots it into a light javelin that flies point-first and pierces troops and vehicles (keeps 95% damage per unit instead of 70%). Aircraft and fixed gun emplacements cannot be grabbed. Vehicles no longer drop crystals. Kaiju sprites are drawn `CONFIG.spriteDrop` (8px) below the physics floor so feet sit on the road.
- **Hit feel (`FEEL` in `src/config.ts`).** Connecting hits freeze the simulation briefly (hitstop scales with damage, longer on collapses and topple landings; none for Ultimate waves). Struck buildings jolt away from the blow and flash, keep a jagged hole where each hit landed (up to 14, scaled with squash), and shed bouncing debris chunks (own cap, separate from particles). Buildings 200px or taller topple away from the blow as a rigid rotation about the base corner (~1s), then crush the structures, ground units and cars under their full height. The nearest building takes height × 0.5 (not scaled by kaiju stage) and each further building in the path takes 35% of the previous one; a building knocked over by another falls at 35% strength per generation, so chains die out. Crush damage is credited to the player (score/quota/Ultimate unless the topple came from an Ultimate), and can topple the next tower for chain reactions. Fallen towers leave a rubble ridge across the span. Shorter buildings keep the vertical squash.
- One crystal meter is HP/evolution. Provisional start 24/100; upward 35/75 and downward 25/65 thresholds, one-second protected transform. Stage scale is 1x/1.4x/2.8x for stages 1/2/3 (dimensions, reach and projectile origins scale); fixed camera zoom. Full HP overflow charges Super, which lasts ~20 seconds and cannot be extended/recharged during activation. Inactive stored Super survives devolution provisionally; activation requires full HP at Stage 3. Active Super ends below 65.
- Player Ultimate is invulnerable/uninterruptible; its damage cannot recharge its meter even after fissures outlive activation. Minor shots do not stagger; strong blasts interrupt charges and knock back with anti-stunlock protection. No self-damage.
- Fixed block-tier rosters: police/patrol; soldiers/APCs; tanks/helicopters/artillery/emplacements; jets/bombers; low-cap arena support. **Squads (`MILITARY_FEEL.squads` in `src/config.ts`):** reinforcements arrive as a whole squad, a core plus escorts from one side, staggered offscreen (e.g. POLICE RESPONSE: 6 squad cars + 4 cops; ARMOR COLUMN: 2 tanks + 6 soldiers; AIR STRIKE: 3 jets), announced once by a banner with the head count ("◀ ARMOR COLUMN ×8") plus pulsing edge arrows. Each tier rotates through its templates; destruction adds up to `squadEscalate` escorts. The next squad comes once at most `squadClear` (30%) of the current one is left, after a `squadBreather`, or after `squadMax[tier]` seconds if you ignore it. A squad that would not mostly fit under the tier cap (`squadMinFit`) waits rather than arriving as stragglers. One soldier per squad carries the radio. Cops, soldiers and squad cars are drawn and collide at about 1.8x/1.25x their old size so a squad reads on screen. Bounded active/projectile/wreck counts, indefinite replenishment, city scaling and destruction pressure. Mobile pursuit and aircraft passes; stationary guns remain fixed. All military may only fire while onscreen; launched shots continue.
- **Telegraphed heavies:** tanks track the kaiju with a dashed aim line, lock (`lockAt`, solid blinking line) and fire the shell at the locked point; helicopters rake with a short gun burst then close a rocket-lock reticle before a rocket pair; jets paint a dashed strafing strip on the street. Moving after the lock dodges. Hitting a unit mid wind-up interrupts it: no shot, a stun (`stunSeconds`, stars overhead) and `interruptPoints` plus `interruptUltimate`. **Spotters:** every `spotterEvery`-th soldier carries a radio (blinking antenna); left alive and onscreen for `spotterSeconds` it calls a big marked artillery strike on the kaiju (a closing ring and a dashed line from the spotter warn you from halfway), killing it first cancels the call. **Small arms are flavour:** bullet damage x `bulletStage` per stage (half at Stage 1, nothing at Stage 3, sparks only); shell/rocket/bomb/artillery damage went up to keep total pressure in readable spikes.
- Weapon-specific rhythms and visible projectiles; bombs/artillery mark ground impact. Only rockets/bombs are interceptable; cosmetic harmless interception, no reward. Full-radius one-time explosive damage affects player/military, never building HP. Friendly-fire kills grant no player points/crystals/Ultimate/quota. Rival military hits are cosmetic.
- **Destruction with weight:** every military kill carries a cause (`melee`, `ranged`, `thrown`, `crush`, `ultimate`, `blast`). Vehicles and aircraft explode: hit-stop scaled by mass (longest on thrown/ranged kills), a lumpy fireball with a shockwave ring and rising smoke, debris chunks, a street scorch mark, a directional camera kick and, for tanks, the turret cartwheeling off. Road vehicles (patrol/APC/tank/artillery) become burning wrecks that tumble with the blow (vehicle physics) and can be grabbed and thrown again; after a thrown or ranged kill the flying wreck itself knocks into other targets. Heavies (mass ≥ `blastMass`) go up in a secondary blast that catches other military, credited to whoever made the kill, so clustered armour chain-reacts. Downed helicopters/jets/bombers spin down trailing fire and crash once on the street with a bigger blast. Troops leave a splat; three quick stomps pop `STOMP ×3`. Knocked-back ground units hop (troops fly in an arc). Police/soldiers auto-squash; at Stage 2+ (`crushStage`) walking into a ground vehicle crushes it, at Stage 1 they stay passable and do no contact damage. **Getting hit:** the kaiju flashes white then red, jolts away from explosions, gets hit-stop and a directional camera kick, keeps brief scorch marks where it was struck, and the HP bar shows a draining ghost of what was lost; bullets just spark off the hide. Damaged vehicles smoke. Three tiny civilian variants, fixed street/cars per layout, one-time 1–3 building occupants, escape/squash with no replenishment or crystal/Ultimate rewards. Cars crumple permanently. Enemy-induced collision destruction grants no player rewards.

**Artifact build:** `npm run build:artifact` (`node build-artifact.mjs`) is the standard publish path. The page is ~0.5 MB; the art ships beside it, listed in `dist-artifact/files.json` (published path -> local file) for one publish. Strips stay individual PNGs in `public/assets/` (never modified); at build time `tools/pack_sprites.py` (Python 3 + Pillow) packs each kaiju form's strips into one sheet in `dist-artifact/assets/sheets/` (`<kaiju>.webp`, `<kaiju>-stage<n>.webp`, lossless WebP, so pixel-exact) and writes an atlas into the page where `src/presentation.ts` has `/*__ATLAS__*/`; `drawSprite`/`holdPoint` read frames from the sheet through `cell()`. In the normal `dist/` build the atlas is empty and each strip loads as its own file. Every kaiju's base idle and the ART_SLOTS art stay loose so the menu loads without pulling a whole sheet, and a run only downloads the sheets of the kaiju being played. If Python/Pillow is missing the build warns and falls back to one file per strip (which can pass 255 files). Flags: `--png` makes 256-colour PNG sheets instead of WebP (for browsers without WebP, mean error ~1/255); `--inline` (`npm run build:artifact:inline`) embeds everything in one self-contained page as base64, only while it stays under the 16MB page limit. Publisher limits: 255 files per publish, 511 per Artifact version, 15 MB per file. The build prints the file count and sizes.


**Sprite loading:** boot loads only the slot art and each kaiju's base idle. `loadKaijuArt(name, stage)` (`src/presentation.ts`) loads one kaiju's strips, the stage on screen first, and drops other kaiju's; the selection, progress, drill and free-play screens call it ahead of play.

**Sprite size:** run `python3 tools/optimize_sprites.py` on new strips before committing. It re-saves strips with at most 256 colours as indexed PNGs and recompresses the rest, replacing a file only when the decoded pixels are identical and the file is smaller.

**Hitstop:** direct blows freeze the game as before. Follow-up hits (shockwaves, flying rocks and lava, burning pools, punted cars) freeze it at most once per `FEEL.hitstopEcho` seconds, so one landing in a dense street is one freeze, not a string of them.

**Benchmark:** `npm run perf` plays a drill in headless Chromium and prints sprites fetched, frame-time percentiles and hitstop freezes around street dives (`--scale 2 --throttle 4` for a high-DPI, slow-CPU run; `PERF_DIR=dist-artifact` to test the artifact build). Headless Chromium renders in software, so compare runs with each other rather than reading the numbers as device frame rates.
