# Kaiju Arcade — M7 QA build / M5 combat pending

Browser arcade destruction game, implemented incrementally from the supplied Master Prompt and Final GDD. Current build has a five-city campaign, 25 fixed layouts, military/civilians, local persistence, roster previews, Free Play, intro and ending/gallery flows. **The user requested M6 after M4; M5 was skipped.** All unlocked identities can now be selected with temporary geometric visuals, but they share the existing player combat, stage dimensions/stats and Seismic-style Ultimate preview. Ratings are provisional display data, not implemented per-kaiju tuning. Rivals still use the basic shared M4 preview moveset. Individual kaiju movesets, boss evolution/Ultimates, full knockback interactions and boss introductions remain M5. No claim that M5 is complete.

## Launch and checks
Requires Node.js 24+; no package downloads or runtime dependencies.

```
npm run build
python3 -m http.server 8080 --directory dist
```

Open http://localhost:8080. `npm test` builds then runs deterministic rule/state and actual-game-loop tests. `npm run check` checks emitted JavaScript syntax. `npm run qa` runs the complete 25-block keyboard simulation and writes `qa/playthrough.json`. See `QA_REPORT.md` for exact results and release blockers. Native Node TypeScript stripping is used; no TypeScript typechecker or lint tool is configured. Production is a static site. HTTP previews use a non-security-sensitive local ID fallback when crypto.randomUUID is unavailable.

`npm run build:artifact` writes `dist-artifact/index.html`: one self-contained page for publishing as a claude.ai Artifact (stylesheet inlined, all modules bundled into one classic script, sprites embedded as data URIs, no outside requests except Google Fonts). It reads `src/` and `public/` directly, so it does not need `npm run build` first. The Artifact viewer did not render the multi-file `dist/` build, so publish this file instead. Any script error shows as a red bar at the bottom of the page.

## Controls and flow
A/D move; H grab what's in front (car, van, bus, any wreck, an enemy patrol car/APC/tank/artillery piece, a newsstand/stronghold barricade, a lamppost, or at Stage 3 a whole building up to mid-rise size) and carry it overhead, then H/J/K throw it (hold W to lob it upward at aircraft); W climb the side of a building (grab, W up / S down, hang in place when idle, Space to jump off, mantles onto the roof; J while clinging is a one-armed punch into the wall, `climbPunch`, an 8-frame 256x256 strip per stage generated with PixelLab from that stage's climb loop frame 0); S stationary crouch; Space jump; stand on any rooftop; J repeated presses for the three-hit light combo; K tap/hold and release heavy; L horizontal ranged spine (Mogurodon on the ground: Tremor Slam; Kaiban on the ground: Debris Shotgun); U full-meter Seismic Rupture (Kaiban: Stampede); I full Stage-3 HP and full Super charge; Esc pause; the pause menu's **Moves & Controls** panel lists the active kaiju's signature moves and the shared combat moves (Moves tab) and movement/climbing (Controls tab), from `moveList()` in `src/presentation.ts` (key notation: `+` held, `/` alternatives, `›` in sequence). The in-game hint is now just a short 'ESC: PAUSE · MOVES & CONTROLS' for the first 8 seconds of a block. No crouch-jump. **Movement and aerial attacks (`MOVE` in `src/config.ts`):** hold Shift or double-tap A/D to run (1.8x; the double-tap opens with a 0.2s dash burst at 2.7x and stays latched until both keys are released); running into a building shoulder-barges it (`bargeDamage`, 1.5x during the dash, on a cooldown) once you have a run-up (`bargeRunUp` px x stage scale covered running the same way; each hit spends it, so holding run against a wall cannot repeat) and bowls over troops; a running jump keeps run speed in the air and goes slightly higher, and jump height grows a little with stage (`jumpVelocity × stageScale^0.25`). Steering into a wall while airborne grabs it without W (leap-grab); if your feet are within `ledgeGrab` body heights of the roof you pull straight up onto it. Pushing into the wall while clinging climbs like W, and Space with the away direction held kicks off the wall into a running leap. S in the air is the Slam: a straight dive (`diveSpeed`, a little steering) that hits the roof under you for `diveDamage × diveRoofMult` plus everything in `diveRadius`, scaled up by the drop height; if the roof gives way you keep plunging into whatever is below, and on the street it rolls out a short shockwave both ways. S+J (crouched light) is the Pound: it beats down on whatever you stand on, so on a rooftop it hammers that building (combo multipliers apply; plays `ultPound`, falling back to `heavySlam`), and on the street it stomps troops, cars and newsstands at your feet. Covered by `tests/movement.test.ts`. Forms can override the borrowed Slam art with their own `dive` (played from the start of the dive, held on its last frame; with `pivot` and `spinFrom` the game rolls it forward about that point at `diveSpin` rad/s) and `slamLand` (played from impact). Mogurodon Stage 1 has both: `mogurodon-s1-dive.png` tucks from the airborne gallop into a quills-out spike ball (frames 0-2 of a 9-frame PixelLab generation from the jump-air pose, bottom-aligned, 28 fps so the ball shows for most of a short drop), and `mogurodon-s1-slam-land.png` is frames 1-8 of a generation from that ball resting on the ground to the base pose (seed 11): squash flat in a dust ring, rebound, burst out of the ball and settle. Eye restored with `fix_eye.py --region 115,140,170,195 --max-err 9000` (the curled frames have no visible eye), then `fill_pinholes.py` and `remove_specks.py`. Mogurodon Stage 2 (`mogurodon-dive.png`/`mogurodon-slam-land.png`, base form) and Stage 3 (`mogurodon-s3-dive.png`/`mogurodon-s3-slam-land.png`, a crystal-studded ball) are made the same way (dive frames 0,1,3 for Stage 2 to skip a specky frame, 0-2 for Stage 3; slam seed 11 for both; pivots are each ball's alpha centroid; eyes restored with `--region 110,132,185,205` and `92,110,185,202`). Kaiban still borrows `jumpAir`/`heavySlam`. **Run art:** while running, a form's `run` loop replaces the sped-up walk (1.3x faster during the dash burst). Mogurodon Stage 1's `mogurodon-s1-run.png` is an 8-frame bounding gallop generated from the base with the base as the last frame (seed 0; the closing duplicate is dropped), 15 fps; the two airborne frames stay lifted so the run bounces. The eye on the leap frames needed `fix_eye.py --radius 34 --max-err 12000 --only 2,3,4,5` because the head travels ~30px. Stage 2 (`mogurodon-run.png`, seed 0, the longest reach) and Stage 3 (`mogurodon-s3-run.png`, seed 11, with an airborne gather mid-cycle) are made the same way from their bases; eyes via `fix_eye.py --radius 34` with each form's region, Stage 2 also `remove_specks.py ... 256 12` for dust flecks. **Cannonball roll:** two ways in. Run + S on the ground curls up on the spot and rolls the way you are running (base power). Or Slam: if A/D is touched at any point during the dive (latched on the key press, so even a one-frame tap counts), or the dive came out of a running leap, the landing keeps the ball rolling that way, on the street or a rooftop (a roof the slam crashes through drops you to whatever is below first). It rolls (`rollSpeed` x walk speed x sqrt(stage scale), `rollSeconds`) for forms whose dive strip spins (Mogurodon); input steers nothing, attacks/grabs are ignored, Space jumps out with run speed, and holding the opposite direction bursts out early. It hits each troop, car (punted), newsstand, growth, rival and stronghold crystal once (`rollDamage` x the slam's drop power). The first wall takes `rollWallDamage` and the ball ricochets back with a hop (`rollHop`, at most `rollAfterBounce` seconds left); the second wall or running out of time ends it by playing `slamLand` (from the squash after a wall, from the rebound frame otherwise). Fullscreen button on the page. Keyboard required.

Main Menu → New Campaign → skippable 12-second asteroid intro → exactly three letters → unlocked kaiju selection → campaign route → Begin City → five blocks → City Conquered → campaign route → next city. Continue loads the last city-boundary checkpoint. New Campaign confirms before replacing an unfinished run. Mogurodon is initially selectable; existing and newly earned rival unlocks enable their identities in Campaign and Free Play. Their distinct attacks/stats remain M5 and this limitation is shown at selection. Locked characters show static silhouettes/question marks, cannot be selected or previewed. An unlocked selection has animated idle stand-ins for all three stages and four provisional 1–5 ratings. Combat Drills retain the M3 tier selector on the original NYC map, do not touch campaign state, and are not leaderboard eligible.

## Campaign rules
- Order: New York/Kaiban, Mexico City/Tlézcatl, Paris/Belial, Hong Kong/Myrmex, Tokyo/Sargathoth. Order after NYC remains an editable implementation default.
- Every city has five hand-authored building/population layouts with 4/6/8/8/4 screen widths. Districts are packed with solid, wall-to-wall buildings you must smash through, climb or hop across; only tiny newsstands are walk-through. The original authored NYC layout survives as the Combat Drills map, and the old packed Lower Manhattan wall is kept as `DRILL_BLOCK`, which Combat Drills loads. **Open layouts (NYC Blocks 1/2/4, pilot):** buildings stand in clusters separated by streets and plazas; the player spawns mid-map (`BlockDef.start`), can roam both ways, and leaves by either the west or east exit once the quota is met. Each has named landmark towers (`L` preset: high value, stepped crown/spire, street-level gold name banner) and hidden crystal caches (an occasional pink window glint, exposed vein when damaged). Landmarks/caches pay score plus Ultimate charge (`EXPLORE` in `src/config.ts`) and never extra crystals. A bottom-strip minimap shows the whole block: skyline, gold landmarks, exposed caches, hostiles, objective/rival, exits, view window and player. Other cities still use the packed layouts. Runtime expands reusable building presets, never generates layouts procedurally.
- Blocks 1/2/4 require 75% of building value, then the player must physically enter the eastern exit. 100% earns one Perfect bonus. Block results show destruction/objective status and block/campaign totals. Backtracking stays within the current block.
- Block 3: fortified central crystal, 700 provisional HP, fixed defenses and normal reinforcements. Destroying the crystal latches the objective and drops 35 collectible shards; it does not fill HP directly. Walk to the eastern exit to advance. Building quota does not gate this block.
- Block 5: locked four-screen destructible arena, limited military, basic rival conventional HP bar, shared telegraphed melee/ranged attacks, foot pursuit, physical blocking and no contact damage. Only player damage hurts rival. Rival death immediately wins the city before later incoming hits. No boss crystal drops. These encounters intentionally lack M5 character-specific/evolution/Ultimate behavior and skippable boss intros.
- HP/evolution, Ultimate, stored Super charge and active Super duration carry across blocks. Interstitials freeze simulation. Transient input/charge/cooldowns and per-block entities reset. Beginning the next city resets HP to Stage 1, Ultimate/Super and city score; previous city totals remain banked.
- Pause Restart City requires confirmation and resets Block 1, all current city points/damage penalty, HP/evolution/Ultimate/Super. Earlier banked scores remain. Quit warns that current city progress is lost; Continue starts its Block 1. No individual block restart in campaign.
- Death finalizes the run, removes its checkpoint and records its total once. No campaign retry after death. New campaigns remain available; drills can retry.

## Local storage and scores
Two independent versioned keys: `kaiju-arcade:permanent:v1` (unlocks, conquered cities, gallery slots, Top 10) and `kaiju-arcade:campaign:v1` (run ID, initials, kaiju, next city, banked score). Saves occur at the initial pre-city boundary and after a city is conquered. No mid-block writes. Between-city Continue starts the next city at Stage 1. Permanent progress survives death/restart/new campaigns. Corrupt/unsupported saves and blocked storage are handled without crashing; failed storage displays a notice and in-memory play still works.

Score is earned points minus actual HP damage penalty, including healed damage. Current city penalty persists across blocks. Top 10 includes completed and failed campaigns, sorted by total (negative scores allowed), with initials, kaiju, cities and outcome. Run IDs and completion latches prevent duplicate records/rewards. Drills never write records, unlocks or checkpoints.

## Combat and military
- **Traffic and vehicles (`VEHICLES` in `src/config.ts`, `src/vehicles.ts`).** Parked cars plus passing traffic (cars, vans, buses) in two road lanes: eastbound in the far lane behind the kaiju's feet, westbound in the near lane in front. Traffic enters from off-screen, brakes when the kaiju is ahead, U-turns and flees faster; each district/stronghold has a traffic budget (5 per screen, none in arenas or drills) and traffic pays half points so it cannot be farmed. Melee, spines and Ultimate waves punt vehicles into tumbling projectiles; stepping squarely on one flattens it (the body's outer edge is a grab zone). Thrown/punted vehicles damage buildings, military, the rival, objectives and growths, and knock other vehicles flying; mass slows them and scales damage, throws also scale with stage. They bounce and settle as grabbable, smoking wrecks. Carrying slows movement slightly and blocks climbing; a stagger, transform or Ultimate drops the vehicle. Grabbing an enemy ground vehicle captures it: it stops fighting and pays its kill points (no crystals, no wreck). Lifting a structure 50px or shorter destroys it for score/quota and leaves no rubble. At Stage 3 the kaiju can also rip up whole buildings up to mid-rise size (up to 240px tall and 115px wide, so every `s`/`m` preset but no `h` tower or taller, never landmarks; `liftHeightStage3`/`liftWidthStage3` in `FEEL`): the building is destroyed for score/quota on lifting, carried overhead at its full size as a `building` prop with mass from its footprint (area/2500, clamped 3-6), and breaks into rubble where it lands instead of settling as a re-grabbable wreck. Grab targets are ranked by their gap from the body's leading edge, so whatever is directly in front wins over props under the wide Stage 3 body. Street lamps (every 450px, formerly backdrop art) are props: walking through one knocks it flat, a hit snaps it off, and grabbing uproots it into a light javelin that flies point-first and pierces troops and vehicles (keeps 95% damage per unit instead of 70%). Aircraft and fixed gun emplacements cannot be grabbed. Vehicles no longer drop crystals. Kaiju sprites are drawn `CONFIG.spriteDrop` (8px) below the physics floor so feet sit on the road.
- **Hit feel (`FEEL` in `src/config.ts`).** Connecting hits freeze the simulation briefly (hitstop scales with damage, longer on collapses and topple landings; none for Ultimate waves). Struck buildings jolt away from the blow and flash, keep a jagged hole where each hit landed (up to 14, scaled with squash), and shed bouncing debris chunks (own cap, separate from particles). Buildings 200px or taller topple away from the blow as a rigid rotation about the base corner (~1s), then crush the structures, ground units and cars under their full height. The nearest building takes height × 0.5 (not scaled by kaiju stage) and each further building in the path takes 35% of the previous one; a building knocked over by another falls at 35% strength per generation, so chains die out. Crush damage is credited to the player (score/quota/Ultimate unless the topple came from an Ultimate), and can topple the next tower for chain reactions. Fallen towers leave a rubble ridge across the span. Shorter buildings keep the vertical squash.
- One crystal meter is HP/evolution. Provisional start 24/100; upward 35/75 and downward 25/65 thresholds, one-second protected transform. Stage scale is 1x/1.4x/2.8x for stages 1/2/3 (dimensions, reach and projectile origins scale); fixed camera zoom. Full HP overflow charges Super, which lasts ~20 seconds and cannot be extended/recharged during activation. Inactive stored Super survives devolution provisionally; activation requires full HP at Stage 3. Active Super ends below 65.
- Player Ultimate is invulnerable/uninterruptible; its damage cannot recharge its meter even after fissures outlive activation. Minor shots do not stagger; strong blasts interrupt charges and knock back with anti-stunlock protection. No self-damage.
- Fixed block-tier rosters: police/patrol; soldiers/APCs; tanks/helicopters/artillery/emplacements; jets/bombers; low-cap arena support. **Squads (`MILITARY_FEEL.squads` in `src/config.ts`):** reinforcements arrive as a whole squad, a core plus escorts from one side, staggered offscreen (e.g. POLICE RESPONSE: 6 squad cars + 4 cops; ARMOR COLUMN: 2 tanks + 6 soldiers; AIR STRIKE: 3 jets), announced once by a banner with the head count ("◀ ARMOR COLUMN ×8") plus pulsing edge arrows. Each tier rotates through its templates; destruction adds up to `squadEscalate` escorts. The next squad comes once at most `squadClear` (30%) of the current one is left, after a `squadBreather`, or after `squadMax[tier]` seconds if you ignore it. A squad that would not mostly fit under the tier cap (`squadMinFit`) waits rather than arriving as stragglers. One soldier per squad carries the radio. Cops, soldiers and squad cars are drawn and collide at about 1.8x/1.25x their old size so a squad reads on screen. Bounded active/projectile/wreck counts, indefinite replenishment, city scaling and destruction pressure. Mobile pursuit and aircraft passes; stationary guns remain fixed. All military may only fire while onscreen; launched shots continue.
- **Telegraphed heavies:** tanks track the kaiju with a dashed aim line, lock (`lockAt`, solid blinking line) and fire the shell at the locked point; helicopters rake with a short gun burst then close a rocket-lock reticle before a rocket pair; jets paint a dashed strafing strip on the street. Moving after the lock dodges. Hitting a unit mid wind-up interrupts it: no shot, a stun (`stunSeconds`, stars overhead) and `interruptPoints` plus `interruptUltimate`. **Spotters:** every `spotterEvery`-th soldier carries a radio (blinking antenna); left alive and onscreen for `spotterSeconds` it calls a big marked artillery strike on the kaiju (a closing ring and a dashed line from the spotter warn you from halfway), killing it first cancels the call. **Small arms are flavour:** bullet damage x `bulletStage` per stage (half at Stage 1, nothing at Stage 3, sparks only); shell/rocket/bomb/artillery damage went up to keep total pressure in readable spikes.
- Weapon-specific rhythms and visible projectiles; bombs/artillery mark ground impact. Only rockets/bombs are interceptable; cosmetic harmless interception, no reward. Full-radius one-time explosive damage affects player/military, never building HP. Friendly-fire kills grant no player points/crystals/Ultimate/quota. Rival military hits are cosmetic.
- **Destruction with weight:** every military kill carries a cause (`melee`, `ranged`, `thrown`, `crush`, `ultimate`, `blast`). Vehicles and aircraft explode: hit-stop scaled by mass (longest on thrown/ranged kills), a lumpy fireball with a shockwave ring and rising smoke, debris chunks, a street scorch mark, a directional camera kick and, for tanks, the turret cartwheeling off. Road vehicles (patrol/APC/tank/artillery) become burning wrecks that tumble with the blow (vehicle physics) and can be grabbed and thrown again; after a thrown or ranged kill the flying wreck itself knocks into other targets. Heavies (mass ≥ `blastMass`) go up in a secondary blast that catches other military, credited to whoever made the kill, so clustered armour chain-reacts. Downed helicopters/jets/bombers spin down trailing fire and crash once on the street with a bigger blast. Troops leave a splat; three quick stomps pop `STOMP ×3`. Knocked-back ground units hop (troops fly in an arc). Police/soldiers auto-squash; at Stage 2+ (`crushStage`) walking into a ground vehicle crushes it, at Stage 1 they stay passable and do no contact damage. **Getting hit:** the kaiju flashes white then red, jolts away from explosions, gets hit-stop and a directional camera kick, keeps brief scorch marks where it was struck, and the HP bar shows a draining ghost of what was lost; bullets just spark off the hide. Damaged vehicles smoke. Three tiny civilian variants, fixed street/cars per layout, one-time 1–3 building occupants, escape/squash with no replenishment or crystal/Ultimate rewards. Cars crumple permanently. Enemy-induced collision destruction grants no player rewards.

## Architecture / replacement hooks
- `src/config.ts`: provisional building, combat, military/weapon and campaign tuning.
- `src/levels.ts`: city themes, presets expanded into 25 fixed layouts, civilians and parked cars.
- `src/campaign.ts`: pure campaign transitions, versioned persistence, validation and leaderboard.
- `src/presentation.ts`: roster metadata/provisional ratings, confirmed ending titles, intro timing, selection/Free Play/gallery gating, optional art slots and temporary Canvas presentation.
- `src/rival.ts`: basic conventional-HP M4 boss preview, isolated for M5 expansion.
- `src/combat.ts`: HP/evolution, attacks/combos/charge, Ultimate/Super, damage attribution/penalties and stagger.
- `src/rules.ts`: building damage/collision, quota/perfect rules, stronghold damage and objective gating.
- `src/military.ts`, `src/population.ts`: entity simulation and attribution.
- `src/game.ts`: input, simulation composition, camera, UI, Canvas rendering; update separated from rendering.
- `public/`: responsive 16:9 shell and asset slots. Art hooks are `monster`, `drawBuilding`, `drawCampaignObjective`, `drawMilitary`, `drawPopulation` and `background`.

**Art:** `public/assets/mogurodon.png` is the first final sprite (transparent, keyed from the supplied render and downscaled to 444×231). Sprites are registered in `SPRITES` in `src/presentation.ts` and used by gameplay, selection previews and the ending scene; kaiju without a sprite fall back to the geometric silhouettes. Mogurodon's base form is its Stage 2 design. Every Stage 2 strip is generated from it with PixelLab and registered with `S2_NATIVE` (scale 194/256, anchor 128), so it draws at the old width and foot position; frame counts and fps are unchanged (they are the timing the other forms fall back to). The previous Stage 2 strips were a darker brown recolour built on an older base. Strips (all 256x192 except the 256x256 climb): 8-frame idle and walk loops closed on the base pose; light combo `mogurodon-swipe-right.png` (near-claw overhead swipe, 24 fps), `mogurodon-swipe-left.png` (far-arm swipe: the far arm rises behind the head and slashes across while the near leg stays planted, 10 of 12 generated frames, 26 fps; the first generation swung the near arm again, so the prompt pins the near leg), `mogurodon-bite.png` (lunge-bite, 20 fps); heavy rear/slam cut from one 16-frame rear-and-slam generation (rear = frames 0-4, slam = 7-15 from the peak into the crash and dust spikes) plus a 4-frame hold from the peak pose; ranged tail-and-quill fling (the detached quill PixelLab drew flies backwards and is erased; the game draws the projectile) and a crouched quill-bristle shot; crouch down, breathing loop, crouch up (reversed); jump rise, air loop and landing, bottom-aligned; Seismic Rupture roar (8 of 17 frames, 0,2,3,5,8,10,12,16, so the shockwave crash is impact frame 5) and an 8-frame two-claw ground-pound loop; climb grab, loop and mantle with the gripping claws on the wall line at frame x=167 (PixelLab painted the wall as a thin brown post at x=224, erased with a 1px outline redrawn where it covered the body; the mantle starts 23px further back and eases to 0); grab (a pebble PixelLab drew at the claws is erased), carry and carry-walk loops with per-frame `hold` points on the fists, and a throw (re-rolled without any object in the prompt: the first one drew a log). **Kaiban moves (`src/game.ts`, tuning in `COMBAT`):** *Debris Shotgun* (L on the ground): the scoop strip plays and on its impact frame (frame 5 standing, 4 crouched) `debrisCount` rock chunks fan out from the tusks, from flat and fast (`debrisAngle[0]`, `debrisSpeed[1]`) to high and lobbed, under `debrisGravity`. Each chunk is a projectile that stops on the first target it meets (buildings, troops, aircraft, vehicles, growths, the rival, the stronghold crystal, interceptable enemy shots), so point-blank most of the fan lands on one target (6 x `debrisDamage`) while at range it spreads out or sails over; chunks crumble on the street, so the range is short. Speeds and lifetime grow with sqrt(stage scale) like the Tremor Slam; `debrisCooldown` replaces the ranged cooldown. Airborne or clinging he fires the shared single shot. *Stampede* (U): the roar strip plays, and on its impact frame a short bellow blast (`bellowRange`/`bellowDamage`, Ultimate waves) knocks back what is close. When the roar ends he charges the way he faces, `stampedeReach` times the stage scale out (fixed at activation; at Stage 1 shorter than Seismic Rupture's `ultimateRange`, so Stage 2 charges 1.4x and Stage 3 2.8x as far, and as much faster, in the same time) and back to where he started, at whatever speed fills the rest of the Ultimate, with gravity on and no building collision; he turns early at the world edge. Every building his body (plus a little in front) touches is destroyed outright, landmarks included: tall ones topple the way he is charging, the facade blows out ahead of him at three heights, with `stampedeCrunch` seconds of hitstop and heavy shake. Troops, vehicles, growths, the rival and the stronghold crystal take `stampedeDamage` as Ultimate damage once per pass, with `stampedeKnockback`; enemy shots in the way are destroyed. Once the Ultimate ends, anything still standing pushes him out as usual. *Gore Charge* (running): his run reuses each form's Stampede gallop (`run` = the `ultPound` strip); a running barge into a building does `goreMult` times the normal barge, troops take `goreUnitMult` damage and knockback, and loose cars in his path are punted high (`goreLift`) instead of stamped flat. *Meteor Drop* (his Slam): dive strips tip into a tusks-first plunge (Stage 1, frames 0,2,4,8) or rear up and plunge fists-first (Stage 2/3, frames 0,1,4,8), bottom-aligned and held on the last frame (no spin, so no roll); `slamLand` is frames 1-8 of a generation from that pose on the ground to the base (seed 0 for both: crater burst and heave out / fists smash, squash low and push up). On landing, besides the normal slam, he flings `meteorRocks` Debris-Shotgun rocks, alternating sides, from `meteorAngle[0]` fast to `[1]` lobbed, scaled by sqrt(stage scale) and drop power. *Pound* uses a `pound` strip when a form registers one: Kaiban Stage 1 reuses the rear-and-stomp heavy slam, Stage 2/3 the overhead fist hammer (light1); before this it fell back to `ultPound`, which for Kaiban is the gallop. All are covered by `tests/kaiban-moves.test.ts`.

**Tlézcatl moves (`src/game.ts`, tuning in `COMBAT`):** *Flame Jet* (L on the ground) is held, not tapped: `jetStart` plays (inhale, jaws thrown open), then he breathes a cone of fire from the jaws for as long as L is held (at least `jetMinBurst`, so a tap is a short burst) and the fuel bar lasts, then `jetEnd` closes the jaws. Fuel drains over `jetSeconds` of breathing and refills at `jetRegen`/s whenever he is not breathing; running it dry locks the jet (gauge reads COOLING) until it is back to `jetRelight`. The HUD gauge over him shows FLAME while it is below full. The cone is marched out from the strip's `mouth` point in 8-unit steps, `jetWidth` wide at the jaws to the far end at `jetRange` (both times sqrt(stage scale)), and stops at the first solid building, which burns; where it meets the street it washes along it at road level for `JET_WASH` (0.6) of its remaining reach, so aiming down sweeps fire across the road. Point-blank against a wall it still draws a short splash. Everything in the cone (troops, aircraft, vehicles (punted at `jetCarPush`), growths, the rival, the stronghold crystal) takes `jetDamage` every `jetTick` (pierces), and interceptable rockets and bombs that fly into it burn up. Building ticks call `hit(..., quiet)`: no hole, hitstop or shake per tick unless the building comes down. W/S tilt the flame up to `jetUp` / down to `jetDown` degrees at `jetTurn` deg/s; S aims instead of crouching while he breathes (pressing L while crouched stands him up), and the `jetAim` strip shows the frame whose head angle (`angles`) is nearest the aim, with the flame starting from that frame's `mouth`. He creeps at `jetSlow` and can turn; J/K/H/L and jumping are ignored while breathing, and being hit, leaving the ground or the Ultimate snuffs it. Airborne or clinging he fires the shared single shot. **Artifact build:** `node build-artifact.mjs` writes one self-contained `dist-artifact/index.html` for publishing as a claude.ai Artifact (16MB limit, base64 sprites add a third). If the sprites exceed an 11MB budget, `tools/shrink_sprites.py` re-saves the largest as 256-colour PNGs in `dist-artifact/sprites/` (mean error ~1/255, `public/assets` untouched) until they fit; the build fails if the page still goes over 16MB.

**Artifact build with separate sprites:** `npm run build:artifact:files` writes the same page without the embedded sprites (about 0.3 MB) plus `dist-artifact/assets/` and `dist-artifact/files.json`, the list to pass as the publisher's supporting files. Use this once the single page nears 16 MB: sprites are no longer limited by the page size or inflated by base64, and the game only downloads the kaiju being played. Limits to watch: 255 files per publish, 511 per Artifact version, 15 MB per file.

**Sprite loading:** boot loads only the slot art and each kaiju's base idle. `loadKaijuArt(name, stage)` (`src/presentation.ts`) loads one kaiju's strips, the stage on screen first, and drops other kaiju's; the selection, progress, drill and free-play screens call it ahead of play.

**Sprite size:** run `python3 tools/optimize_sprites.py` on new strips before committing. It re-saves strips with at most 256 colours as indexed PNGs and recompresses the rest, replacing a file only when the decoded pixels are identical and the file is smaller.

**Hitstop:** direct blows freeze the game as before. Follow-up hits (shockwaves, flying rocks and lava, burning pools, punted cars) freeze it at most once per `FEEL.hitstopEcho` seconds, so one landing in a dense street is one freeze, not a string of them.

**Benchmark:** `npm run perf` plays a drill in headless Chromium and prints sprites fetched, frame-time percentiles and hitstop freezes around street dives (`--scale 2 --throttle 4` for a high-DPI, slow-CPU run; `PERF_DIR=dist-artifact` to test the artifact build). Headless Chromium renders in software, so compare runs with each other rather than reading the numbers as device frame rates.
